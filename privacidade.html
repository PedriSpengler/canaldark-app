Política de privacidade — Canais Dark Publicador

Última atualização: 17 de novembro de 2026.

Quem usa

O app é usado apenas por Pedro Spengler, nas contas Google dos canais dele. Não há usuários externos.

Dados acessados

Com a permissão concedida na tela do Google (escopo youtube.force-ssl), o app lê a lista de canais da conta e os dados dos vídeos do próprio canal, e altera título, descrição, tags, categoria, idioma e miniatura desses vídeos.

Armazenamento

O único dado guardado é o token de acesso do OAuth, mantido em variáveis de ambiente privadas do dono. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
